# 铁锈代码编写器

把《诺瓦御科：v1.15代码表.xlsx》变成**图形化编写工具**：不用背语法、不用查表，
点一点就能写 Rusted Warfare 的单位代码，边写边看效果和错误。

- **图形化编写**：字段按类型给控件（开关 / 滑块 / 调色板 / 中英对照下拉 / 素材下拉 / 标签块）
- **像素级显示**：所有贴图和 Canvas 关闭抗锯齿，缩放时保持硬边，不再出现模糊边缘
- **单独预览**：代码预览、单位效果预览（比例图 + 武器数据）、参考手册，都是实时刷新
- **更清爽的顶栏**：新建 / 模板 / 打开 / 保存 / 动画 / 体检常驻，另存为、导入、导出、使用说明收进「更多」菜单
- **编辑区导航**：顶部「跳到段」下拉 + 当前文件字段筛选；按 `/` 聚焦筛选，Esc 清空
- **手机快捷保存**：有未保存修改时，右下角会出现「保存」按钮，不用再展开菜单
- **指出错误**：69 条规则 + 悬空引用检查，从缺 `name` 到"引用了模组里不存在的特效"，点一条直接跳到出错的字段
- **背包（可复用模块）**：把常用键或整段特效存成模块，换到别的单位一键追加，不用复制粘贴
- **资源管理器**：像文件管理器一样浏览模组，图片带缩略图、挑出没被引用的素材、重命名 / 软删除 / 新建单位
- **模组体检**：哪些素材从没被引用、哪些引用了却找不到文件、全模组重复键、全局变量清单、all-units 模板里到底有什么
- **手机 / 平板可用**：自适应单栏界面 + 底部导航，局域网模式下手机也能改同一份模组文件
- **能打包成应用**：Windows 单文件 exe（双击即用、无需装 Python）；安卓可打包成远程 APK 或真正独立的 APK（内置 Python/Flask，无需电脑）

## 一、启动

双击 **`启动.bat`**（推荐：自动装依赖 → 生成数据 → 起服务 → 打开浏览器）。

手动等价于：

```bat
pip install -r requirements.txt
python build_data.py      :: 从 代码表\*.xlsx 生成 data\code_table.json（只需一次）
python server.py          :: 启动后浏览器访问 http://127.0.0.1:8760
```

> 关闭那个黑窗口 = 退出工具。服务只监听本机 127.0.0.1，不联网。端口被占用时会自动往后找。

## 二、界面三块

```
┌─ 左：代码库 / 资源 ──┬─ 中：图形化编辑区 ──────┬─ 右：侧栏（可收起） ──┐
│ 📚 代码库：搜索代码  │ 每个 [段] 一张卡片      │ 背包 / 代码预览       │
│ 资源：文件管理器  │ 字段按类型给控件        │ 效果预览（可视化）    │
│ 悬浮看说明，点击加入 │ ? 看代码表原文，× 删除  │ 错误检查（点击定位）  │
└─────────────────────┴────────────────────────┴──────────────────────┘
```

- **面板可缩放**：左/中/右之间的竖条可以拖动改宽，双击竖条恢复当前窗口的默认宽度；键盘聚焦竖条后可用 `←/→` 微调、`Home` 复位。
- **右侧栏可收起**：点顶栏「侧栏」按钮或右侧栏顶部的小圆钮，右栏收起成一条带图标的栏；点「背包 / 代码 / 效果 / 检查 / 参考」图标会展开并直接切到对应页签。宽度和开合状态会记在浏览器里。
- 手机上仍走原来的单栏 + 底部导航，分隔条和图标栏自动隐藏。

### 左：代码库
- 代码表里 **1311 条代码**全部收录，搜索框同时搜 **代码名 / 中文名 / 说明文字**（搜“血”“攻击”“price”都行）。
- 条目右边的标签是类型（bool / int / float / time / color / ref / list…），决定它在中栏用什么控件。
- 鼠标悬停有说明气泡；点击就把这条代码加进中栏对应段（该段不存在会自动建）。
- 「全部 / 已用 / 未用」用来过滤；“还差什么”很好用。
- 「快速骨架」：基础单位 / 战斗单位 / 建筑物 / 建造者·工厂 / 运输载具 / 资源采集器 / 特效动画动作。

### 中：图形化编辑区
- 每个 `[段]` 一张卡片，段名可改（`turret_1` → `turret_2`），左侧色条按段类型区分；改段名和字段都会实时同步右侧代码预览。
- 编辑区上方有「跳到段」下拉和字段筛选：大文件不用一路滚；按 `/` 聚焦筛选，Esc 清空。
- 字段控件按类型自动切换：
  - **bool** → 开关（统一写 `true/false`；旧文件的 `on/off`、`yes/no` 会自动规范；也支持自定义表达式）
  - **数字** → 输入框 + 滑块（说明里写了 0-1 之类的范围就自动带上）；值写错时会变成文本框并提示“这里应该是数字”
  - **time** → 数值 + 单位（s / ms / 帧）
  - **color** → 调色板 + 十六进制
  - **tags** → 标签块，回车添加
  - **image / 音效** → 输入框带内置素材下拉（代码表里的 50 个内置图 + 28 个内置音效）
  - **单位引用** → 下拉列出代码表内 175 个原版单位 + 本文件里定义过的单位名
  - **movementType / displayType 等** → 中英对照下拉框
  - **资源类字段**（`addResources`、`price`、`resourceUsage`、`generation_resources`…）→
    输入框带**全局变量下拉**，下面直接列出本文件/模组里已定义的全局变量（如「本文件已定义：电磁 等 69 个」），
    不用再去翻 all-units.template 抄名字；
  - **特殊写法字段**（`canBuild_#_name`、`action_#_[actionKey]`、`animation_TYPE_[animationKey]`）→
    按代码表登记为「special value」，编辑器给文本框、提示「特殊写法·填字符串」，
    **不会**再误报「应该是数字」（之前 `canBuild_11_name: setRally` 会被误判成数字缺失）。
- 字段右侧：`?` 打开代码表原文说明与例子，`×` 删除；段头 ↑ ↓ 调序、🗑 删段。
- **「当前段」提示**：点哪个段卡片，它就会亮起来并标记「当前段·新字段加这里」——
  从左侧代码库点代码时，新字段就是加到它里面（同类型有多个段时，添加后的提示也会写明加到了
  哪一个，比如 `turnSpeed → 已加入 [turret_6x]`，避免加到不想要的段里）。
- 顶部「整理排序」= 按代码表推荐顺序重排段与字段，方便对照检查。

### 全局变量的识别（不需要手动操作）

打开任意单位文件后，工具会**在后台自动扫描它所属的模组**（自动从单位目录往上找到模组根），
所以：全局变量/全局资源的判定、`addResources` 的下拉提示、缺失引用检查都是现成的，
不用先点「扫描整个模组」。属于别处定义（比如 all-units.template）的变量会被判成
「本文件里没有，但模组其它文件里有」（灰色提示），只有**整个模组都找不到**才算警告。

### 动画制作器（顶部「动画」按钮）

RW 的动画就是 `[animation_名字]` 段里的关键帧，代码表里的写法是：

```
[animation_开门]
blendIn: 0.1s
blendOut: 0.1s
arm1_0s:    {x: 0, y: 0, dir: 0}
arm1_2s:    {x: 0, y: 33, dir: 0}
arm1_99999s:{x: 0, y: 33, dir: 0}     ← 99999s 常用来“保持”最后状态
body_1s:    {frame: 3, scale: 1.5}    ← 主体只支持 frame / scale
effect_0.3s:{x: 0, y: 6, name: 爆炸2}  ← 特效按“名字”引用
turret1_0.5s:{x: 3, y: 6}
```

制作器把这些变成可视化操作：

- **关键帧表格**：选部位（主体 / 炮塔N / 腿N / 胳膊N / 特效）→ 填时间和数值 → 添加；
  重复部位+时间会自动覆盖，点 ✎ 把某帧载回表单改，✗ 删除。
  表单只列出该部位**允许的属性**（主体只给 frame/scale、腿/胳膊给 x/y/dir/alpha、特效给 x/y/name 下拉）。
  更新已有帧时只覆盖表单里显示的字段，未显示的属性（例如旧帧里的自定义字段）会保留；清空某个输入才会删除对应属性。
  选中关键帧后直接修改 x / y / dir / alpha 会立即写回当前帧并刷新预览，不需要先点「更新关键帧」；
  重新点选/载入同一帧时数值会保持。
- **2D 舞台拖动**：暂停后在画布直接点选补件/炮塔/腿，出现橙色 X 轴、绿色 Y 轴和中心手柄；拖 X 只改 x，拖 Y 只改 y，
  拖中心同时改 xy，并在当前播放头自动生成/更新关键帧。右侧表单数值会同步变化。
  拖动时按住 `Ctrl` 按网格吸附，网格默认 5，可在播放条「网格」里修改；胳膊/腿选中后还有紫色 `↻` 旋转手柄，
  旋转同样即时写入 `dir`，按住 Ctrl 时按网格角度吸附。
  画布支持缩放：滚轮以鼠标位置为中心缩放，「− / 百分比 / ＋」按钮、`重置视图` 恢复 100%，
  中键拖动平移，`回到中心` 只把平移归零并保留当前缩放。
- **撤销 / 重做**：`Ctrl+Z` 撤销、`Ctrl+Y` 重做（也支持 `Ctrl+Shift+Z`），项目栏也有按钮；
  覆盖增删/移动关键帧、拖动补件、修改 xy/属性、缓动、参数、载入/导入等操作。
- **作品代码**：右侧「代码」页实时显示写入 ini 的作品代码，可一键复制；项目 JSON 不混入作品。
- **项目 / 作品**：顶部「项目」栏支持导入/导出项目（`animation.json`，含原始关键帧、缓动、参数、步长），
  以及导入/导出作品（游戏用 ini）。导出作品默认打包 zip 到程序根目录 `output`，也可自定义路径；
  作品 zip 只含 ini，不含 animation.json。
- **关键帧列表**：条目多时可滚动；列表上方「＋ 添加」展开编辑表单，底部「关键帧编辑」可收起，让列表一次显示更多条目。
- **选定部位贴图**：选择主体 / 炮塔 / 腿脚 / 特效后，画布左上角显示该部位贴图；预览用黄色虚线框高亮对应部位，
  没有关键帧时也会静态显示，方便对齐贴图和位置。
- **流畅度**：制作器打开时暂停背后的动画卡片，暗色遮罩不做全屏模糊；播放画布不限帧率、跟随屏幕刷新率；
  播放 / 拖时间轴时画布自动降到 1x（暂停恢复高清），拖时间轴只移动当前点、不重建整条时间轴；
  播放时播放头用 CSS 合成动画跟随屏幕刷新率；暂停/拖动时用独立 Canvas 绘制，均不触发布局重算。
  部件多（例如十几个 arm）的单位会把同一张贴图的解析合并成一次请求，最多 4 个并发，并合并贴图回调重绘，
  避免每帧对每个 arm 重复请求导致 `ERR_INSUFFICIENT_RESOURCES`。
- **非线性缓动**：每个关键帧可选「线性 / 缓入 / 缓出 / 缓入缓出 / 柔和 / 回弹 / 弹跳 / 自定义 cubic-bezier」，
  旁边实时画出曲线。缓动优先取段首帧；段首是线性时取段尾帧，所以最后一帧也能控制“进入它”的那一段。
  RW 本体只会在关键帧之间线性插值，因此写入/复制时会自动把缓动**烘焙**成中间关键帧（默认开启，
  可在底部「烘焙缓动」关闭；关闭后游戏内就是线性）。
  烘焙按底部「步长」从段首到段尾固定采样（默认 0.05 秒，即每 50ms 一帧），而不是固定几个点。
  缓动源（原始稀疏关键帧和缓动曲线）只保存在浏览器 `localStorage`，既不写入 ini，也不产生额外文件；
  再次打开同名动画会自动恢复。若 ini 被外部工具改过，则不会恢复，避免覆盖外部修改。
- **时间轴**：底部是完整时间轴，按部件分轨显示所有关键帧。
  拖关键帧改时间、拖播放头 / 点刻度定位、Ctrl+滚轮或 ＋/− 缩放、`适应`一键铺满、`吸附`按 0.05s 对齐；
  点关键帧会载入右侧表单，`＋ 播放头处加帧`可直接在当前时间补帧，选中后 `Delete` 删除。
- **帧动画**：右侧「帧动画」页读取主体贴图并按 `total_frames / frame_width / frame_height` 切成缩略图帧条；
  点任意帧可在播放头插入单帧，或填 `0-9` / `0,2,4` 序列、帧率、开始时间、往返，一键生成主体 `frame` 关键帧。
  生成会替换该时间段内已有的主体关键帧（会先确认），并保留原主体的 scale 等属性。
- **时间轴预览**：画布按贴图实时播放（主体、炮塔、腿脚都会按各自的安装位置摆放），
  ▶/⏸、拖动进度、0.25×~2× 倍速、循环，右侧实时显示各部件当前插值后的数值；
  找不到贴图的部件画成彩色方块占位，动作照样看得出来。
- **参数行**：条件（idle/move/attack/生产中等）、blendIn/blendOut、帧时长缩放、播放频率、往返播放。
- **载入**：① 当前文件里已有的动画段；② 背包里的动画模块；③ **搜整个模组的动画**
  （实测你这份模组里有 38 个动画段，比如 `animation_开门`，直接载进来改）；
- **写回**：点「写入代码」，编辑器里就出现/更新 `[animation_xxx]` 段（内容与代码表语法一致），
  也可以「复制代码」或「存进背包」留给别的单位用。
- 「效果预览」里每个动画段还有一张小卡片自动播放，点一下直接进制作器编辑。

> 预览时长上限 30 秒；超过 30 秒（常见于 `99999s` 的永久保持帧）按 5 秒循环预览。
> 想完整看，在制作器「时长」里填数字即可。时间轴键盘：`Space` 播放/暂停、`←/→` 微调 0.05s（Shift 0.5s）、
> `Delete` 删除选中关键帧、`Esc` 关闭。

### 右：五个标签页
| 标签 | 内容 |
|---|---|
| **背包** | 可复用模块（键 / 整段）+ 缺失引用补全 |
| **代码预览** | 最终 ini 文本，行号 + 语法高亮；**出错的行标红、可疑的行标黄**；可复制 / 下载 / 另存 |
| **效果预览** | 单位卡片（名称 / 移动类型 / 科技等级 / 标签 / 血量·护盾·能量·造价条）+ 比例图 + 数值卡 + 武器卡 |
| **错误检查** | 全部规则的结果，分错误 / 警告 / 提示，点一条直接跳到出问题的字段 |
| **参考手册** | 代码表全部参考值：内置爆炸效果、音效、图像、单位表、行动框类型、路径点类型…以及地图代码表 |

**效果预览**的比例图按真实尺寸画：1 地块 = 20 像素，画出本体半径、占地 footprint（建筑）、
攻击范围圈、视野圈、每个炮塔的位置，并叠一个“半径 20px 的标准坦克”作参照。
缩放太小时网格自动加粗；攻击距离写成 99999（全图）时按 120 格缩小显示并在图上注明。

**贴图与特效预览**（效果预览下半部分）：

- **正常 / 死亡贴图切换**：画布工具条上有「正常 / 死亡」开关。正常状态用 `image`；死亡状态用
  `image_wreak`（RW 官方拼写，同时兼容 `image_wreck` / `image_dead`）。死亡状态只绘制整张残骸图，
  炮塔开关自动禁用；没写 `image_wreak` 时会退回正常贴图并在画布右上角与说明里提示。

- **整机拼装图**：比例图里画的不只是主体，而是**拼好的整机** ——
  主体 + 每个炮塔（按 `x/y` 摆位、共用主体贴图条时按炮塔序号取帧）+
  腿脚/胳膊（`attach_x/y` 到 `x/y` 的中段与末端贴图、按 `drawDirOffset` 旋转）+
  贴花（按 `layer` 决定上下层级：shadow → beforeBody → 主体 → afterBody → onTop）+
  附属子单位（`onCreateSpawnUnitOf` 按单位名跨文件找到它的贴图）。
  绘制顺序严格按 **`drawOverBody`**（代码表未登记、实际存在的键，已补进索引）：
  **炮塔默认 `true`**（画在主体之上），填 `false` 画在主体之下；
  **腿/胳膊默认 `false`**（主体之下），`true` 才画在主体之上。
  画布工具条上可**单独开关「炮塔」**（`invisible: true` 的隐形炮塔本来就不画）。
  攻击距离是全图（比如 370 格）时，机体在正常比例下会缩成一个点，
  这时自动进入**「整机特写」**：放大到机体、省略范围圈，图例会说明；
  取消勾选「整机特写」就回到显示范围圈的全景。
- **画布缩放 / 平移**：滚轮以光标为中心缩放（20%–2000%）、按住拖动平移、
  双击复位；工具条上也有 ＋ / − / ⟳ 按钮和当前缩放百分比。
  换打开别的文件时自动复位。
- **特效预览**：把本文件里每个 `[effect_*]` 段做成一张卡片，**按代码填的数值分割贴图实现关键帧**：
  `frame_width / frame_height`（与 `total_frames` 二选一）严格切出每一帧，按 `life` 把
  `animateFrameStart → animateFrameEnd` 铺满整个生命周期（支持 `animateFramePingPong` 往返），
  卡片底部有**关键帧条**（每帧一个小格，当前帧高亮），并按 `life` 从 `scaleFrom` 渐变到 `scaleTo`；
  卡片上标出帧尺寸 / 当前帧号 / 缩放 / 优先级 / 是否跟随单位；点卡片可以**放大预览**（大画布 + 大帧条 + 参数表）。
  没有动画代码时单位本体静止显示第 0 帧（不做无中生有的循环）。
- 贴图引用会自动解析：同目录文件名、`ROOT:/路径/图.png`、`SHADOW:x.png` 都能找到真实文件；
  找不到就明确写「找不到贴图文件」，`NONE`/`AUTO` 视为未设置；
  用了游戏内置贴图条的（`stripIndex: effects` 这类）会说明「无法预览」而不是假装没有贴图。
- 单位引用了但没定义的 `[effect_xxx]` 也会列出来（红边卡片），知道缺什么。

**武器卡**按 `[turret_N]` → `projectile` 解析：直接伤害、范围伤害 / 半径、开火间隔（帧或 2.2s 都认）、
**每秒伤害估算**、弹速、存活帧数、炮塔坐标、可攻击目标（空中 / 地面 / 水下）。

## 三、背包：模块化，不再复制粘贴

你写单位时总有些反复出现的配置（一套装甲参数、一个死亡爆炸、一套被动技能）。背包就是把它们攒起来复用：

1. **存**：在中间编辑区，点字段右侧的 **☆** 勾选任意几个键，或点段头的 **❐** 把整个 `[段]` 存成模块；
   在「背包」页签里起个名字（比如"标准装甲""死亡爆炸"），保存到 `data/backpack.json`。
2. **用**：换到别的单位文件，点 **＋ 追加到当前文件** ——
   - 键模块会合并进对应的段（段不存在会自动建，遇到同名键默认跳过，勾上「应用时覆盖同名键」就覆盖）；
   - 整段模块直接追加一整段，**段名重复会自动加序号**（`effect_爆炸` → `effect_爆炸_2`）并提示你。
3. 模块能改说明、能删，删除不影响已经写进单位文件的内容。

### 缺失引用补全（就在背包页签下半部分）

它会把代码里**引用了、但找不到定义的**东西列出来，分五类：
**特效**（`CUSTOM:xxx`、`explodeEffect`、`trailEffect`…）、**动作**（`alsoTriggerAction`、`fireTurretXAtGround`…）、
**单位**（`unitsSpawnedOnDeath`、`spawnUnit`、canBuild 的 `name`…）、**全局变量**（`addResources`、`price: 名字=值`…）、**素材**（图片/音效文件名）。

每条都告诉你"用在哪里"，并给几个一键操作：

- **从背包补全**：背包里正好有同名模块时，一键插进去；
- **＋ 建一个空段**：按类型生成合理骨架（`[effect_xxx]` 带 life/image/帧数，`[action_xxx]` 带 text/displayType，`[global_resource_xxx]` 带显示名/颜色）；
- **建段并存入背包**：顺手存进背包，下次别的单位直接复用；
- **在模组里找 / 定位 / 复制文件名**。

勾上 **扫描整个模组** 后判定更准：区分「本文件没有但模组其它文件里有」（灰，不算问题）
和「**整个模组里都没有**」（红，会同时计入错误检查的 E140–E144）。
例如它在《遗骸与血统 0.4a》的 AI核心作战中枢t4 里查出 4 个 `explodeEffect: CUSTOM:战术防御波…`
引用的特效在模组里从未定义 —— 这类笔误/漏文件平时很难发现。

## 四、资源管理器（左侧「资源」）

像文件管理器一样浏览模组目录，不用再切到 Windows 资源管理器：

- **目录浏览**：点文件夹进去，`↑` 上一级、`🏠` 回模组根、`⟳` 刷新、`📂` 用系统资源管理器打开当前目录；
- **目录缓存 / 重试**：成功读取过的目录会留在内存，返回上级时先显示缓存再后台刷新；网络请求中断会自动重试 4 次，避免 `Failed to fetch` 导致目录空白。
  顶部**面包屑**可以直接点任意一层跳转，路径栏也可以改路径回车跳转。双击 = 打开（ini 进编辑器、图片/音频预览、其它用系统程序打开）。
- **排序与视图**：可按名称 / 最近修改 / 体积 / 类型排序（升降序），列表视图 ↔ 缩略图视图一键切换，偏好会记住。
- **多选**：点「选择」进入多选，勾选多个文件/文件夹后可**批量复制路径**或**批量移到回收站**；
  也可以用 `Ctrl+Click` / `Shift+Click` 临时多选。
- **键盘操作**：聚焦列表后 `↑/↓` 选择、`Enter` 打开、`Delete` 软删除、`F2` 重命名、`Esc` 退出多选/取消选择。
- **图片带缩略图**（滚到附近才加载，大目录切到「全部」不会一次请求几百张），音频点 👁 能直接试听；每行悬停有快捷按钮：
  `✎` 在编辑器里打开、`👁` 预览、`📂` 在 Windows 里定位、`✏` 重命名、`🗑` 移到回收站；缩略图视图里收进 `⋯` 菜单。
- **右键菜单**：文件可「用系统默认程序打开 / 复制完整路径 / 重命名 / 软删除」，
  目录可「打开 / 在模组里搜索内容 / 设为模组根目录 / 在这里新建文件夹或单位文件」。
- **找没被引用的素材**：勾上「只看未引用素材」，就从目录浏览切换成**全模组的平铺清单** ——
  读出模组体检的结果，按体积从大到小列出所有没被任何 ini 引用的图片/音效（实测你这份模组 91 个 / 11.2 MB），
  带缩略图、所在目录、大小，可以逐个预览、定位、重命名或清理。
- **找重复键**：勾上「只看重复键」，切换成**全模组的重复键文件清单**，按多余键数量排序；
  普通目录浏览时，含重复键的文件和它所在的文件夹都会带红色 `⚠` 标记。
- 文件类型筛选：**代码 + 素材 / 只看代码 / 只看图片音频 / 全部**；名字筛选框支持高亮匹配。
- **＋ 新单位**：在当前目录按模板（7 种骨架）新建一个单位 ini 并直接打开；**＋ 文件夹**建目录。
- **删除是软删除**：移动到模组根下的 `_回收站_时间戳` 文件夹，不真删，随时能翻回来（回收站目录在列表里带 🗑 标记）。

## 五、模组体检（顶部「体检」）

一次扫描整个模组（785 个 ini/template，结果缓存 3 分钟），四个页签：

**素材引用**
- **未被引用的素材**：按体积从大到小列出（实测某模组 2323 个素材里有 91 个从没被引用，合计 11.2 MB；
  最大的两个是 2.4 MB 的 YouTube 音频和一个文件名叫 `，.ogg` 的误存文件），点名字复制路径。
- **引用了但找不到文件**：反过来查"代码里写了 `xxx.png`，模组里却没有这个文件"。
- 判定方式：把每个素材文件名在所有 ini/template 文本里搜一遍（地图、脚本、外部工具的引用不参与判断）。

**全局变量**
- 模组里全部 `[global_resource_*]` / `[resource_*]` 清单：变量名、显示名、颜色色块、全局/局部、来源文件；
- **被使用但从没定义过**的变量（`addResources: 某某=1` 却没有对应资源段），会列在最上面。

**all-units 模板**
- 直接看清楚 `all-units.template` 里有什么：路径、段数行数、**对全体单位生效的 [core] 默认键**（带中文名）、
  **全局资源/变量**（带颜色色块与"隐藏/有图标"标记）、**模板段 `[template_*]` 列表**、其它段；
- 有「在编辑器里打开它」按钮，可以直接改全局模板；
- 如果你扫的是模组里的一个子文件夹，它会自动往上找到真正的模组根并提示你切换。

**重复键**
- 扫描全模组 `.ini / .template` 的**同一段内重复键**，键名不区分大小写；不同段里的同名键不算重复。
- 每个文件列出：段名、键名、重复次数、行号、每个值；并标记「值相同 / 值不同」。
- 顶部的「重复键」页签带文件数徽标；点「打开」会关闭体检并载入该文件，方便直接改。
- 左侧文件管理器新增 **「只看重复键」**：切换成全模组的重复键文件清单；普通目录里的文件、以及含有重复键文件的文件夹都会带红色 ⚠ 标记。
- 只做检测，不会自动改源文件。

## 六、错误检查会指出什么

工具把代码表当“字典”，把 RW 的实际写法当“语法”，共 69 条固定规则（E001–E130）+ 5 条悬空引用检查（E140–E144，需要扫描模组后才有），常用的：

- **重复内容**（错误检查页顶部）：
  - 三类统计 chip（可点展开明细）：`E024` **值完全相同的键**（黄）、`E020` **值不同的重复键**（红）、
    `E010` **重复的段**（紫）；每个 chip 带 🧹 一键清理。
  - **明细列表**：每组重复逐条列出 —— 段名、键、每个值（保留的标绿"保留"、多余的描红）、
    ◎ 定位（跳到字段并高亮）、以及**单条删除按钮**（"删除多余 ×1" / "只留最后 ×1" / "合并这一对"）。
  - 「一键全部清理」一次处理完三类（有确认提示）；没有重复时显示「✓ 没有重复键、也没有重复段」。
    实测在你模组里就找到并合并了 `[effect_冲击波]`、`[turret_8]`、`[turret_9]` 这些重复段。
- **缺失必需项**：没有 `[core]`、没有 `name`、没有 `maxHp`、没有 `radius`、建筑没 footprint…
- **写错地方**：同段重复键、键放错段、完全没登记的未知代码、重复的段名。
- **类型不对**：布尔写了中文、数字写了文字、时间格式不对、颜色不是 `#RRGGBB/#AARRGGBB`、列表用了中文逗号「，」。
- **中文冒号陷阱**：`price：100` 会被标错（导出时自动改成英文冒号）。
- **`.md` 特效库也算数**：不少模组把特效/模板库写在 `.md` 文件里（用 `copyFrom: ROOT:/通用特效/爆炸素材库.md`
  引用），所以扫描、搜索、引用判定都会读 `.md`；引用到这类特效时，
  「贴图 / 特效预览」会**跨文件把它加载进来**（卡片上标注「来自 爆炸素材库.md」），
  并用**那个文件所在的位置**去解析贴图，而不是误报"整个模组里都没有"。
- **引用完整性**：炮塔的 `projectile: 5` 找不到 `[projectile_5]`、抛射体没有任何炮塔使用、
  炮塔没写 projectile、有 `[attack]` 却没有炮塔、有炮塔却没有 `[attack]`。
- **打不出去**：三种目标全是 false、`maxAttackRange` 是 0、溅射有 `areaDamage` 却没写 `areaRadius`、
  非瞬发抛射体 `speed: 0`、抛射体一点伤害都没有。
- **建造链**：`isBuilder: true` 却没有 `[canBuild_N]`、canBuild 段没写 `name`。
- **建筑**：footprint 不是 4 个数字、左右/上下写反、半径比占地还大。
- **数值合理性**：`techLevel` 不在 1–3、`shieldRegen / selfRegenRate` 每帧数值过大（会算给你每秒是多少）、
  `radius` 为 0、`mass` 为 0、护盾没有恢复速度…

**不误报**也是设计目标。工具认得这些真实写法：`${ ... }`、`self.xx`、`max(0, sin(...))`、
`price: 8000,蓝晶=2100`、`price: energy=4`、`delay: 2.2s`、`stripIndex: effects`、
`mutator30_ifUnitWithTags`（占位符键）、`@copyFromSection`、`dont_load: true` 的定义文件、
`*.template` 模板文件、`[resource_x]` 与 `[global_resource_x]` 混用等。
回归测试：5 个真实模组共 48 个现成单位文件，79% 零错误，其余多为真实隐患
（顺手查出过模组里 `[turret_8]`、`[turret_9]`、`[effect_冲击波]` 三处重复段）。

## 七、日常工作流

1. **改现成单位**（推荐）：左侧「资源」→ 点开 `.ini` → 改数值 →
   `保存` 写回原文件（或「另存为」留备份）。选过的模组目录会被记住。
2. **做新单位**：`模板` 或左侧「快速骨架」→ 改 `name / displayText / image / price / maxHp /
   radius / buildSpeed` → 看效果预览确认数值手感 → 看错误检查 → `导出`。
3. **从别处搬代码**：`导入` 粘贴整段 ini，解析成卡片，检查完再导出。
4. **复用与体检**：把常用配置勾选存进背包；换单位时一键追加；发布前用「模组体检」清理没用的素材、
   确认全局变量都有定义、看看 all-units 里有什么。
5. **整理素材**：左侧「资源」页找没被引用的图片/音效，重命名或移进回收站；顺手用「＋ 新单位」起新单位。
6. 快捷键：`Ctrl+S` 保存　`Ctrl+O` 资源管理器　`Ctrl+N` 新建　`Ctrl+K` 搜索框　`Ctrl+B` 背包　`Ctrl+E` 切换代码库/资源　`Esc` 关弹窗。

**保存是安全的**：做过载入 → 保存的往返测试（3 个真实文件 191 / 522 / 255 行），
内容逐行一致，只把 `key:value` 规范成 `key: value`（RW 解析时忽略空格），
`#` 注释、`@memory` 行、`${...}` 表达式原样保留。

```
铁锈代码编写器/
├─ 启动.bat                 一键启动（本机）

│   ├─ backpack.json        背包里的可复用模块（自动生成）
```

## 九、手机 / 平板使用

界面本身是自适应的：窗口窄到手机宽度时自动变成**单栏 + 底部导航**（代码库 / 编辑 / 预览 / 资源），
工具栏收进左上角 ☰ 菜单，字段变成"标签在上、控件在下"的大按钮排版，资源管理器每行只留一个 **⋯** 菜单，
图片照常显示缩略图。手机上打开就是能用的。

因为要读写你电脑上的模组文件，手机需要连到你电脑上的服务：

1. 电脑上双击 **`启动-局域网.bat`**（或 `python server.py --lan`）；
2. 它会打印手机要访问的地址，例如 `http://192.168.1.28:8760/`（手机和电脑连同一个 WiFi）；
3. 手机浏览器打开这个地址 → 就是完整工具，改完点保存，文件直接写在你电脑上；
4. 想更像 App：浏览器菜单里选「**添加到主屏幕**」，桌面就会出现图标，打开时没有浏览器地址栏
   （页面底部也会提示一次这个操作）。

> 连不上时优先看 Windows 防火墙：第一次运行会弹"是否允许访问网络"，要选允许；
> 也可以手动放通 8760 端口。局域网模式会监听 0.0.0.0，只在你主动启动时才开启。

## 十、打包成应用程序

### Windows：单文件 exe（已验证）

```
python 打包_win.py            :: 生成 dist\铁锈代码编写器.exe（约 18 MB）
python 打包_win.py --console  :: 保留黑窗口，方便看局域网地址和日志
```

- 双击 exe 即用，**目标电脑不需要装 Python**；会自动打开浏览器界面。
- `static/`、代码表数据、代码表 xlsx 都打进包里；运行时自动解包到临时目录。
- **用户数据（记住的模组目录、背包）写在 exe 同级的 `data\` 目录**，
  所以把 `dist` 整个文件夹拷走（U 盘/网盘）就是绿色版，配置和背包跟着走。
- `dist` 里还会带上 `README.md`、启动脚本和 `代码表\`，方便一起分发。
- 想要局域网：`铁锈代码编写器.exe --lan`（也可以直接跑 `启动-局域网.bat`，它会优先用 exe）。

### 安卓：APK（已验证，实测可编译 ✅）

需要：**Node.js 20+**、**Android SDK**、**JDK 17–23**。缺什么脚本会自己说，也能自己补：

```
双击 打包_安卓.bat
```

脚本流程（每一步都在本机实跑过）：

1. 检查 Node 20+ / Python / Android SDK；
2. 找 JDK 17–23：先看已知位置（`%LOCALAPPDATA%\Android\jdk-21`、Adoptium、Java），
   **Android Studio 自带的 JDK 太新（24+）会自动跳过**（Gradle 8 用不了它）；
   一个都没有时会问你要不要自动下载 Temurin JDK 21（约 200 MB，只下一次）；
3. 问你电脑的局域网地址（默认按 `ipconfig` 猜，回车即用）；
4. 在 **`%LOCALAPPDATA%\RTCoderAndroid`**（纯英文路径）建 Capacitor 7 工程并编译 ——
   必须放这儿，因为 **Android 构建工具不支持中文路径**（AGP 会直接报错）；
5. 产物复制到 `dist\铁锈代码编写器.apk`（约 3.9 MB）。

**手机上装和使用**：

1. 把 `dist\铁锈代码编写器.apk` 传到手机安装（允许"安装未知来源应用"）；
2. 电脑上双击 `启动-局域网.bat`，让服务跑起来；
3. 手机连同一个 WiFi，打开桌面上的「铁锈代码编写器」图标即可 —— 界面和电脑上一样，
   改完保存直接写回你电脑上的模组文件。

> 换电脑/换 IP 后要重新打包（地址是编译时写进 App 的）：
> 改 `%LOCALAPPDATA%\RTCoderAndroid\capacitor.config.json` 里的 `server.url` 重跑脚本，
> 或者直接删掉 `%LOCALAPPDATA%\RTCoderAndroid` 目录让脚本重建。
> 不想装 Android SDK 的话，用上面的「添加到主屏幕」方案，体验基本一样。

### 安卓：真正独立的 APK（内置 Python/Flask，无需电脑）

这是独立版，不是上面的远程壳：

- APK 内部带 Python + Flask + 静态资源
- 启动时由 App 自己在本机 `127.0.0.1:8760` 启动服务
- WebView 加载本地服务
- 安装后电脑可以关机，手机单独使用
- 支持直接读写手机存储里的模组、输出作品 zip

在电脑上构建一次：

```bat
双击 打包_安卓独立.bat
```

或：

```bat
python 打包_安卓独立.py
```

产物：

```text
dist\铁锈代码编写器-独立版.apk
```

构建要求：

- Android SDK Platform 35 / Build-Tools
- JDK 17–21（默认找 `%LOCALAPPDATA%\Android\jdk-21`）
- Python 3.10–3.15（构建用）
- 首次构建要联网下载 Chaquopy 的 Python 运行时和 Flask 依赖

手机上使用：

1. 安装 APK（允许安装未知来源应用）；
2. 首次启动会请求「所有文件访问」权限，用于读写 `/storage/emulated/0` 下的模组；
3. 默认模组根会依次尝试：

```text
/storage/emulated/0/RTmod
/storage/emulated/0/Download/RTmod
/storage/emulated/0
```

也可以在「资源」里点「浏览」手动选择手机上的模组目录。

独立版说明：

- 作品 `output` 默认写到 `/storage/emulated/0/RTCoder/output`，没有权限时退回 App 内部目录；
- 项目 `animation.json`、作品 zip、资源管理器都可用；
- `dist\铁锈代码编写器-独立版.apk` 使用 debug 签名，自己安装够用；上架应用商店需要正式签名；
- 目前只打包 `arm64-v8a`（绝大多数现代手机）；32 位老机型需要改 `abiFilters` 重新构建；
- Android 11+ 的「所有文件访问」是系统特殊权限，侧载才方便；如果只使用 App 内部空间，不授权也能打开界面。

> 原来的 `打包_安卓.bat` 仍然保留，生成的是「连接到电脑局域网服务」的远程壳；独立版请用 `打包_安卓独立.bat`。

## 十一、已知边界

- 「效果预览」的每秒伤害是**估算**（直接伤害 × 每秒发射次数），不考虑装甲、伤害倍率、
  弹道飞行时间、齐射等，只用来看量级。
- 代码表里没登记的键会显示「未知」但仍可编辑（RW 允许自定义段与模板键）。
- 重复段、中文冒号这类问题会指出并给出正确写法，但**不会自动改你的源文件**，
  需要在编辑区改掉（导出文本时会用英文冒号）。
- 资源管理器里的删除是**软删除**（移进模组根的 `_回收站_时间戳` 文件夹），不提供"彻底删除"按钮，
  真要清空自己去那个文件夹删即可。重命名会同步更新编辑器里已打开文件的路径。
- 资源管理器操作的是本机真实文件：它只在你点击时才动作，不会自己改动模组。
